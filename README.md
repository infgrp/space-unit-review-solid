# 대단원 평가하기 입체 영상 (기하 III 공간도형과 공간좌표)

미래엔 기하 교과서 III단원의 **대단원 평가하기** 24문항을 「공간도형」「공간좌표」와 같은 엔진·방식으로 만든 것입니다.

## 구성 (26단계, 영상 약 11분)

- 시작 → 평가 1~24 → 마무리. 문제는 양쪽 벽에 번갈아 서고, 가운데에 그 문제의 3D 그림이 나옵니다.
- 문제를 읽어 준 뒤 5초 멈춥니다(풀이는 보여 주지 않음). 자동 재생도 5초 더 기다립니다.
- 원문 그림의 오류를 고쳐 실었습니다: 7번 그림이 문제와 다른 정사면체였으므로 문제대로(평면 위 이등변삼각형 ABC 와 A 위의 점 D) 새로 그렸고, 그 정사면체 그림(M 은 AD 의 중점)은 그림이 없던 8번에 맞으므로 8번에 썼습니다.
- 원문에 그림이 없는 문항(1, 3, 13~15, 17~21, 23, 24)은 답을 드러내지 않는 상황 그림을 넣었습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `content.js` | 단계 내용: 블록(교과서 한 덩어리)마다 벽 글(`L`), 큰 수식(`big`), 해설 대본(`say`), 그림, 멈춤(`hold`) |
| `figs.js` | 그림 모음: TikZ 좌표 그대로 점·선분·평면·면·직각 표시·각·같은 길이 표시·원·구·원기둥 |
| `index.html` | 엔진(latex2three3d 템플릿 + 위 두 파일에서 단계·글·카메라·그림을 만든다) |

벽에 글이 다 들어가지 않으면 새 쪽으로 넘어가고, 그림은 블록이 바뀔 때마다 그려졌다 사라집니다.

## 조작

- → / Space: 다음, ←: 이전, Home: 처음부터 · 아래 점을 누르면 그 단계로
- 끌기: 회전, 휠: 확대·축소, 오른쪽 끌기: 이동, 두 번 클릭: 원래 시점
- 위쪽 버튼: 🔊 음성 켜기·끄기, 자동 재생(문제 단계는 해설 뒤 5초 더 멈춤), 처음부터
- 시험용 주소: `?step=N`, `?mute`

## 해설 음성

Azure `ko-KR-HyunsuMultilingualNeural`. 대본은 `content.js` 의 `say` 입니다. 고친 뒤 `python make_voice.py`(바뀐 것만) 또는 `--all`.
환경변수 `AZURE_SUBSCRIPTION_KEY`, `AZURE_SERVICE_REGION` 이 필요하며 키는 페이지에 들어가지 않습니다.

## 영상 만들기 (4K 60fps)

```
node record_all.mjs      # 단계마다 따로 녹화(seg/) → video_noaudio.mp4  (크롬이 중간에 멈추면 그 단계만 다시, 다시 실행하면 이어서)
python mix_audio.py      # 해설 + 배경음악 + 자막 → 대단원평가_4K.mp4, 대단원평가_4K.srt
```

- 단계 길이 = 앞 여유 1초 + 해설 + 멈춤(문제 5초) + 끝 여유 1.6초. 멈춤은 페이지의 `HOLDS` 에서 읽습니다.
- 자막은 해설 대본에서 만들며, 소리 나는 대로 쓴 글자 이름을 기호로 바꿉니다(에이비 → AB, 피 프라임 → P′).
- 크롬, ffmpeg, Node 18 이상, Python(numpy, scipy)이 필요합니다. 이 PC에서 4K 녹화는 약 3시간 걸립니다.
